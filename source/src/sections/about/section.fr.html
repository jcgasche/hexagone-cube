Hexagone³ a été écrit par Jean-Charles Gasche, de façon indépendante et bénévole. Il n’a aucun lien avec la SNCF, SNCF Réseau, Île-de-France Mobilités, l’État, la Région ou la Ville de Paris, et personne n’a commandé ni financé l’étude. Son texte, ses figures, ses données et son modèle sont libres de réutilisation, avec mention de l’auteur.

L’auteur

Jean-Charles Gasche a écrit cette étude sur son temps libre, pour montrer que des gares traversantes sous Paris méritent une étude professionnelle. Le projet et chacun de ses choix sont les siens. Le modèle, les dessins et le texte ont été réalisés avec l’aide d’un assistant d’intelligence artificielle (Claude, d’Anthropic) ; chaque chiffre vient du modèle ouvert, que chacun peut relancer.

Contact et corrections

Écrivez à hexagone.cube.paris@gmail.com. Pour signaler une erreur ou proposer une meilleure source, vous pouvez aussi ouvrir un ticket sur la page GitHub de l’étude. Ce qu’une correction change est reporté dans le modèle et dans les deux langues ; voir hypothèses et limites pour les points qui demandent le plus à être vérifiés.

Réutiliser l’étude

Le texte, les figures, les données et le modèle d’Hexagone³ sont sous licence Creative Commons Attribution 4.0 (CC BY 4.0) : chacun peut les copier, les diffuser et les adapter, pour tout usage, à condition de citer l’auteur, de donner le lien vers l’étude et d’indiquer ce qui a été modifié.

Pour la citer : Jean-Charles Gasche, Hexagone³ : des gares traversantes sous Paris, version 4.1, octobre 2026, https://jcgasche.github.io/hexagone-cube/.

Le code source

Le site, le modèle et les données sont publiés sur GitHub, chaque version datée. Le modèle est un ensemble de scripts Python sans paquet à installer ; la page explique comment le relancer et comment chaque chiffre du texte est rempli à partir de ses résultats (voir comment les chiffres sont obtenus).
